# 🧩 Sudoku Solver

Цей репозиторій містить просту реалізацію розв'язувача Судоку на мові програмування Python. Алгоритм використовує метод **backtracking** для знаходження розв'язку.

---

## 📋 Опис

Програма бере на вхід частково заповнену судоку-таблицю (9x9), де незаповнені клітинки позначені нулями `0`, і намагається знайти коректне розв’язання згідно з класичними правилами судоку:

- У кожному рядку, стовпчику та блоці 3x3 числа від 1 до 9 не повинні повторюватися.

---

## 🧠 Алгоритм

- Знаходиться перша незаповнена клітинка.
- Для неї перевіряються всі числа від 1 до 9 на допустимість.
- Якщо число підходить, воно записується в клітинку, і запускається рекурсивний виклик функції `solve`.
- Якщо жодне число не підходить — алгоритм "відкочується" (backtracking).

---

## 🚀 Запуск

Щоб запустити розв'язувач:

```bash
python main.py
```
